# Геометрические формулы

Проект содержит функции для вычисления площади и периметра
плоских геометрических фигур: круга, прямоугольника, квадрата и треугольника.

## Структура проекта

- `circle.py` — круг
- `rectangle.py` — прямоугольник
- `square.py` — квадрат
- `triangle.py` — треугольник
- `docs/` — документация

## Формулы

### Площадь
- Круг: S = πR²
- Прямоугольник: S = ab
- Квадрат: S = a²
- Треугольник: S = ah / 2

### Периметр
- Круг: P = 2πR
- Прямоугольник: P = 2a + 2b
- Квадрат: P = 4a
- Треугольник: P = a + b + c

## Использование

```python
import circle

print(circle.area(2))       # 12.566370614359172
print(circle.perimeter(2))  # 12.566370614359172
```
