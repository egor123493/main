# Техническое задание

## Наименование

C++ Dead Code Inspector — расширение для Visual Studio Code.

## Назначение

Автоматически находить в исходных файлах C/C++ недостижимые строки и неиспользуемые статические функции, отображая результат стандартными диагностическими средствами VS Code.

## Входные данные

Открытый файл или файлы workspace с расширениями `.c`, `.cc`, `.cpp`, `.cxx`, `.h`, `.hpp`, `.hxx`.

## Функции

1. Запуск анализа текущего файла и всего workspace командами палитры.
2. Запуск анализа после сохранения, если включена настройка `cppDeadCode.analyzeOnSave`.
3. Поиск кода после безусловных `return`, `throw`, `break`, `continue` в одном блоке `{ ... }`.
4. Поиск `static`-функций, имеющих определение, но не имеющих вызова в том же файле.
5. Вывод результатов в Problems: строка, сообщение, уровень и код правила.

## Нефункциональные требования

- Расширение не изменяет исходный код.
- Для работы не нужны компилятор и внешние процессы.
- Поддерживаемая среда: VS Code 1.85 и новее.
