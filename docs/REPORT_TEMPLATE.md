# Отчёт: лабораторная работа №3

## Тема

Разработка подключаемого модуля для IDE Visual Studio Code.

## Цель

Изучить механизм расширений VS Code, разработать и подключить плагин с собственной логикой статического анализа исходного кода C/C++.

## Выбранная IDE

**Visual Studio Code**, расширение написано на TypeScript с использованием VS Code Extension API.

## Кратко об архитектуре IDE

VS Code загружает расширения как Node.js-модули. Манифест `package.json` описывает метаданные, требования к версии редактора, команды и настройки. После события активации VS Code вызывает `activate`. Плагин регистрирует обработчики через API, в том числе команды и событие сохранения. Результаты анализа передаются через `DiagnosticCollection`, после чего редактор отображает их в Problems и подсвечивает соответствующие строки.

## Реализованный плагин

Название: **C++ Dead Code Inspector**.

Плагин выявляет недостижимые строки после операторов безусловного завершения управления и неиспользуемые `static`-функции. В отличие от сниппета, плагин анализирует текст, учитывает вложенность блоков и хранит промежуточные результаты в структурах `Map` и массиве объектов `FunctionInfo`.

## Архитектура и алгоритм

Вставьте или приложите схему из `docs/ARCHITECTURE.md`. Опишите запуск команды/сохранение файла, работу `analyze`, создание `Diagnostic` и вывод Problems.

## Тестирование

Проверьте минимум два случая:

```cpp
static void unused() { }
int f() {
    return 1;
    int x = 10;
}
```

Ожидаемый результат: предупреждение для `int x = 10;` и информационное сообщение для `unused`.
