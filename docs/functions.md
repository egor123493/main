# Описание функций

## circle.py

### area(r)
Возвращает площадь круга.

- **Параметры:** `r` (float) — радиус круга
- **Возвращает:** float — π * r²
- **Пример:**

```python
area(2)  # 12.566370614359172
```

### perimeter(r)
Возвращает длину окружности.

- **Параметры:** `r` (float) — радиус круга
- **Возвращает:** float — 2 * π * r
- **Пример:**

```python
perimeter(2)  # 12.566370614359172
```

## rectangle.py

### area(a, b)
Возвращает площадь прямоугольника.

- **Параметры:** `a` (float) — первая сторона, `b` (float) — вторая сторона
- **Возвращает:** float — a * b
- **Пример:**

```python
area(3, 4)  # 12
```

### perimeter(a, b)
Возвращает периметр прямоугольника.

- **Параметры:** `a` (float) — первая сторона, `b` (float) — вторая сторона
- **Возвращает:** float — 2 * (a + b)
- **Пример:**

```python
perimeter(3, 4)  # 14
```

## square.py

### area(a)
Возвращает площадь квадрата.

- **Параметры:** `a` (float) — длина стороны
- **Возвращает:** float — a²
- **Пример:**

```python
area(5)  # 25
```

### perimeter(a)
Возвращает периметр квадрата.

- **Параметры:** `a` (float) — длина стороны
- **Возвращает:** float — 4 * a
- **Пример:**

```python
perimeter(5)  # 20
```

## triangle.py

### area(a, h)
Возвращает площадь треугольника по основанию и высоте.

- **Параметры:** `a` (float) — основание, `h` (float) — высота
- **Возвращает:** float — a * h / 2
- **Пример:**

```python
area(6, 4)  # 12.0
```

### perimeter(a, b, c)
Возвращает периметр треугольника.

- **Параметры:** `a`, `b`, `c` (float) — длины сторон
- **Возвращает:** float — a + b + c
- **Пример:**

```python
perimeter(3, 4, 5)  # 12
```
