# C++ Dead Code Inspector
 
> **Автор:** Егор Басалаев, группа: M3101  
> **Лабораторная работа №3:** разработка плагина для IDE
 
**C++ Dead Code Inspector** — учебное расширение для **Visual Studio Code**, которое выполняет упрощённый статический анализ исходных файлов C/C++. Расширение показывает результаты в стандартной панели **Problems** и подчёркивает проблемные строки прямо в редакторе.
 
## Назначение
 
Цель плагина — автоматически выявлять **недостижимые строки кода** после безусловных операторов передачи управления: `return`, `throw`, `break`, `continue`.
 
Плагин разработан для демонстрации подключения сторонней функциональности к VS Code, работы с Extension API, обработки событий, анализа текста и представления результатов в виде диагностик.
 
## Возможности
 
- Поддержка файлов `.c`, `.cc`, `.cpp`, `.cxx`, `.h`, `.hpp`, `.hxx`.
- Команда анализа текущего открытого файла.
- Команда анализа всех подходящих файлов рабочего пространства.
- Автоматический анализ C/C++-файла после сохранения.
- Вывод предупреждений в панели **Problems** с кодом `unreachable-code`.
- Учёт вложенности блоков `{ ... }`, чтобы `return` из одной функции не влиял на следующую функцию.
- Распространение недостижимости во вложенные блоки: если `return` стоит прямо перед `{ ... }`, весь код внутри этого блока тоже помечается.
- Помечается **весь** недостижимый участок кода до конца блока, а не только первая строка после `return`/`throw`/`break`/`continue`. (не работает с `case`)
- Настройка автоматического анализа через `cppDeadCode.analyzeOnSave`.
## Примеры
 
### Недостижимый код
 
```cpp
int getNumber() {
    return 42;
    int value = 100; // Плагин: недостижимая строка
}
```
 
### Недостижимый код во вложенных блоках
 
```cpp
void funcWithUnreachable() {
    return;
    {
        int l = 0;      // Плагин: недостижимая строка
    }
 
    for (int i = 0; i < 9; i++) {   // Плагин: недостижимая строка
        continue;                   // Плагин: недостижимая строка
        int pivot = 9;               // Плагин: недостижимая строка
    }
 
    int x = 42;                     // Плагин: недостижимая строка
    std::cout << x << '\n';         // Плагин: недостижимая строка
}
```
 
Все строки после `return;` в этом примере находятся в одном и том же блоке (теле функции) либо во вложенных блоках внутри него, поэтому помечаются целиком — независимо от количества уровней вложенности `{ }` между ними.
 
## Ограничения
 
Анализ выполняется на уровне текста (лексически), без построения полноценного AST или control-flow graph, поэтому:
 
- Не распознаются `goto`/метки, `switch`/`case` с fallthrough и условная компиляция (`#ifdef`/`#endif`).
- Несколько операторов в одной строке через `;` распознаются только если вся строка целиком состоит из `return`/`throw`/`break`/`continue`.
- На весь недостижимый участок выводится предупреждение для каждой отдельной строки (а не одно сводное предупреждение на регион, как в GCC/Clang).
- При сильно нестандартном форматировании (например, скобки внутри незакрытых строковых литералов) подсчёт глубины блоков может сбиться.
## Настройки
 
| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `cppDeadCode.analyzeOnSave` | `boolean` | `true` | Автоматически запускать анализ при сохранении файла C/C++. |
 
## Команды
 
| Команда | Идентификатор | Описание |
|---|---|---|
| C++ Dead Code: Analyze Current File | `cppDeadCode.analyzeFile` | Анализирует файл, открытый в активном редакторе. |
| C++ Dead Code: Analyze Workspace | `cppDeadCode.analyzeWorkspace` | Анализирует все файлы `.c`, `.cc`, `.cpp`, `.cxx`, `.h`, `.hpp`, `.hxx` в рабочей области. |
